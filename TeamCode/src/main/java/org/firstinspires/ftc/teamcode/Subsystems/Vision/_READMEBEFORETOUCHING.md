# Vision Module Dependency [EN]

The following package depends on an external library (`IgnitingInnovationAprilTagLibrary-1.0.jar`).
This dependency is a registry of the April Tags in this game's field.
Without this library the April Tag tracking code throws an error as the id of the tag contains null metadata.

# Vision Module Dependency [EL]

Το ακόλουθο _package_ εξαρτάται από μία εξωτερική βιβλιοθήκη (`IgnitingInnovationAprilTagLibrary-1.0.jar`).
Αυτή η βιβλιοθήκη είναι ένα μητρώο από τα _April Tag_ στην φετινή πίστα.
Χωρίς αυτήν την βιβλιοθήκη, ο κώδικας για την αναγνώριση των  _April Tag_ δεν λειτουργεί καθώς ο ταυτοποιητικός αριθμός του _Tag_ αντιστοιχεί σε κενά μεταδεδομένα.
